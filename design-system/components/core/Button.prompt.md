Use for any call-to-action or form submit — the brand has two CTA systems and this covers both.

```jsx
<Button variant="primary">Contact us</Button>
<Button variant="warm" size="lg">Shop the Shade</Button>
<Button variant="ink">Shop Cream</Button>
```

Variants: `primary` (solid navy, square 4px — default on light surfaces like the header and dialog), `warm` (amber/sun pill — use over photography and bright sun-fields, e.g. "Shop the Shade"), `ink` (dark pill — on bright amber backgrounds), `secondary` (quiet sand), `ghost` (text + wood underline on hover), `glass` (warm frosted — over beach video). Sizes: `sm` / `md` / `lg`. Props: `fullWidth`, `iconLeft`, `iconRight`, `disabled`.
